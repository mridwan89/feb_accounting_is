# System Architecture Document (SAD)
## Sistem Informasi Akuntansi - Siklus Pengeluaran (Fase 1)

**Versi:** 1.1 (Desktop/LAN Target)

Dokumen ini mendefinisikan tumpukan teknologi, topologi jaringan lokal, dan struktur data tingkat tinggi untuk pengembangan Sistem Informasi Akuntansi (Modul Pengeluaran) berbasis Desktop.

---

## 1. Tumpukan Teknologi (Tech Stack)

Sistem akan beroperasi sepenuhnya di dalam infrastruktur jaringan lokal (LAN) perusahaan tanpa ketergantungan internet publik.

*   **Aplikasi Klien (Frontend):** 
    *   **Framework:** Electron.js dipadukan dengan React atau Vue.js. Ini memungkinkan pembuatan antarmuka kaya fitur dengan performa mendekati *native* di OS Windows/macOS.
    *   **Distribusi:** Modul *Auto-Updater* untuk menarik pembaruan rilis langsung dari server lokal.
*   **Server Aplikasi (Backend/API):**
    *   **Environment:** Node.js (Express/NestJS) terpusat pada server PC/Server lokal.
    *   **Fungsi:** Mengelola otentikasi sesi, memproses *business logic* (aturan persetujuan PO/PR), dan mencegah akses langsung dari desktop ke database.
*   **Database Server:**
    *   **Engine:** MariaDB. Dipilih karena reliabilitas tinggi untuk transaksi keuangan dan beban konkuren.
    *   **Manajemen:** Administrasi dan eksekusi *query* administratif dapat dilakukan dengan mudah menggunakan Navicat oleh tim pengembang atau administrator internal.
*   **Lingkungan Pengembangan (Local Dev):** 
    *   **Setup:** Menggunakan FlyEnv untuk memastikan standardisasi lingkungan pengembangan lokal antar *developer* berjalan konsisten.
